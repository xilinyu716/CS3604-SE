# 注册页 需求（场景驱动）

## 1. 页面总览
- 页面定位：用户注册，完成账户信息填写、严格校验与手机核验，生成可登录账户。
- 入口与路径：`/otn/regist/init` 页面，主导航与顶部登录/注册入口可达（`frontend/data/注册/中国铁路12306网站.html:216-219,225-259`）。
- 合规提示：显著提示“官方APP下载，目前铁路未授权其他网站或APP开展类似服务内容，敬请广大用户注意”。
- 无障碍与适老化：支持工具栏与“敬老版”切换，表单具备 aria 标签与键盘可操作性（`frontend/data/注册/中国铁路12306网站.html:160-166`）。

## 2. 流程与步骤
- 流程：账户信息 → 手机核验（双向/短信） → 注册成功页。
- 步骤 UI：使用步骤条与分区布局，当前步骤蓝色高亮 `#60C6E7`，非当前为浅灰 `#E3EDF4`（`frontend/data/注册/中国铁路12306网站_files/reg.css:5-11`）。

### 场景
 - 进入手机核验（预校验通过）
  - Given 用户完成必填字段并勾选服务条款
  - When 点击“下一步”按钮 `nextBtn`
  - Then 发起预校验与验证码准备，弹出手机核验窗口（按钮：`frontend/data/注册/中国铁路12306网站.html:945`；预校验：`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）
 - 完成注册跳转成功页
  - Given 手机核验通过（双向或短信）
  - When 点击“完成注册”
  - Then 提交详情并跳转成功页，可能附带微信二维码参数（窗口与按钮：`frontend/data/注册/中国铁路12306网站.html:115-133`；提交：`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）

## 3. 账户信息与字段校验
- 表单：`#registForm`（`frontend/data/注册/中国铁路12306网站.html:412`）。
- 字段清单与规则：
  - 用户名 `userName`：6–30，字母开头，字母/数字/下划线；唯一性校验与空格禁止（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`；输入控件：`frontend/data/注册/中国铁路12306网站.html:415`）。
  - 密码 `passWord`：≥6 且不得与用户名相同；字符集合法、组合要求；强度提示条 `#_div_password_rank`（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`；控件与强度条：`frontend/data/注册/中国铁路12306网站.html:422,425`）。
  - 确认密码 `confirmPassWord`：与密码一致、字符合法（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`；控件：`frontend/data/注册/中国铁路12306网站.html:434`）。
  - 证件类型 `cardType` 与隐藏值 `cardTypeCode`：居民身份证/港澳/台湾居住证/护照/通行证等；切换联动额外字段与提示图示（`frontend/data/注册/中国铁路12306网站.html:441-446,460`；联动逻辑：`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）。
  - 姓名 `regist_name`：3–30；按证件/国家要求中文或英文，禁止中英文混合；“姓名填写规则”链接（`frontend/data/注册/中国铁路12306网站.html:465,467`；规则弹层：`frontend/data/注册/中国铁路12306网站.html:103-114`）。
  - 证件号码 `cardCode`：按证件类型校验格式；焦点显示分隔提示；身份证 18 位自动推导出生日期（`frontend/data/注册/中国铁路12306网站.html:472-473`；分隔显示与自动填充：`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）。
  - 证件有效期 `id_limit_date_end`：适用特定证件，必填（`frontend/data/注册/中国铁路12306网站.html:480`）。
  - 出生日期 `born_date`：可自动填充或手工选择（`frontend/data/注册/中国铁路12306网站.html:486`；日期控件：`frontend/data/注册/中国铁路12306网站_files/data.jcalendar.js.下载:1`）。
  - 性别 `userDTO.sex_code`：单选男/女（`frontend/data/注册/中国铁路12306网站.html:492,495`）。
  - 国家/地区 `nation`：中国/国外切换影响姓名规则与字段要求（`frontend/data/注册/中国铁路12306网站.html:502`；联动逻辑：`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）。
  - 旅客类型 `passengerType`：默认“成人”；选择“学生”显示优惠资质提醒（`frontend/data/注册/中国铁路12306网站.html:909,915`）。
  - 邮箱 `email`：格式校验与自动补全（`frontend/data/注册/中国铁路12306网站.html:919`）。
  - 手机区号与号码 `mobileCode/mobileNo`：预置 `+86/+852/+853/+886`；号码格式与必填规则（`frontend/data/注册/中国铁路12306网站.html:925-926,1011-1012`；格式校验与必填规则：`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）。
  - 服务条款 `checkAgree`：必须勾选，否则阻止提交（`frontend/data/注册/中国铁路12306网站.html:937`；校验：`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）。

### 场景
- 自动填充出生日期
  - Given 证件类型为“居民身份证”且号码 18 位
  - When 完成证件号输入
  - Then 自动填充出生日期 `born_date`（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）
- 邮箱替代手机号（特定证件/国家）

  - When 至少填写邮箱或手机号之一
  - Then 允许进入核验（规则判断与提示：`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）
- 服务条款未勾选阻止提交
  - Given 未勾选 `checkAgree`
  - When 点击“下一步”
  - Then 弹出提示并阻止提交（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）

## 4. 手机核验（双向/短信）
- 弹窗结构：`#dialog_mobile` 包含输入框 `mobile_hy_code`、重发按钮 `mobile_hy_dia_get`、完成与返回按钮（`frontend/data/注册/中国铁路12306网站.html:115-133,121,123,130-131`）。
  - 双向验证：用户发送“999”到 12306，系统回 6 位码，十分钟有效（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）。
  - 短信验证码：直接下发 6 位码，十分钟有效（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）。
  - 倒计时与重发：120s 倒计时控件与“重新获取验证码”按钮（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）。
- 国家代码：按 `all_mobile_codes` 渲染区号下拉（`frontend/data/注册/中国铁路12306网站.html:1011-1012`；渲染逻辑：`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）。

### 场景
- 双向验证流程
  - Given `info_show=='Y'`（需双向验证）
  - When 展示步骤文案并开始倒计时
  - Then 用户输入 6 位码后点击“完成注册”，提交 `regist/subDetail`（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）
- 短信验证流程

  - When 下发 6 位短信并倒计时
  - Then 输入后提交详情并成功跳转（`frontend/data/注册/中国铁路12306网站_files/registGeneral_js.js.下载:1`）

## 11. 验收清单（注册）
- 表单校验完整：用户名、密码/确认、证件类型与号码、姓名、国家/地区、性别、出生日期、手机号/邮箱规则生效。

- 手机核验可用：双向与短信两路径均可完成；倒计时与重发按钮逻辑正确。
- 安全加密有效：密码前端加密提交；后端拒绝明文。
- 无障碍与适老化：错误可读可聚焦；大字号样式覆盖主要元素。
