# 车次列表页（单程查询）需求分层与场景

## 1. 页面概览
- 目标：支持用户在指定出发地、目的地与日期下查询单程/往返车次，进行筛选、排序与下单。
- 范围：`leftTicket/init?linktypeid=dc` 入口页的查询、筛选与结果展示；包含站点/席别/乘车人/日期选择弹窗与无障碍提示。
- 关键入口与控件：查询表单、日期快捷条、筛选面板、结果表格与行内操作。

## 2. 顶部查询表单
- 2.1 行程类型切换
  - 控件：`单程`/`往返`单选框（`frontend/data/车次列表页/车次列表-1.html:570-575`）
  - 场景：
    - Given 用户进入车次列表页
    - When 切换为`单程`或`往返`
    - Then 表单展示对应日期输入控件，`返程日`在单程下禁用（`车次列表-1.html:596-600`）
- 2.2 站点选择（出发地/目的地）
  - 控件：出发地`fromStationText`与目的地`toStationText`（`车次列表-1.html:578-589`）
  - 交互：支持拼音/汉字输入与下拉选择、站点互换（`change_station`）（`车次列表-1.html:584`，站点选择弹窗见`车次列表-1.html:901-907`）
  - 场景：
    - Given 用户在出发地输入框输入站名
    - When 打开站点选择弹窗并选择`北京`或通过键盘上下选择（热门/字母分组）
    - Then 输入框填入所选站点代码与名称（`车次列表-1.html:903-906`）
- 2.3 日期选择（出发日/返程日）
  - 控件：`train_date`与`back_train_date`（`车次列表-1.html:591-599`）
  - 场景：
    - Given 用户定位到`出发日`
    - When 选择合法日期（含周信息）
    - Then 表单记录选定日期，联动日期快捷条高亮（`车次列表-1.html:621-666`）
- 2.4 身份类型
  - 控件：`普通`/`学生`单选（`车次列表-1.html:608-613`）
  - 场景：
    - Given 用户选择`学生`
    - When 点击`查询`
    - Then 系统按学生票规则返回余票与价目信息（结果区展示）
- 2.5 查询触发
  - 控件：查询按钮`#query_ticket`（`车次列表-1.html:615`）
  - 场景：
    - Given 表单信息完整且合法
    - When 点击`查询`
    - Then 发起车次查询，结果区刷新为对应日期与筛选条件的车次列表

## 3. 日期快捷条
- 控件：横向日期列表（`11-23`至`12-07`）（`车次列表-1.html:621-666`）
- 场景：
  - Given 当前选择日期为`11-24`
  - When 点击`11-25`
  - Then 结果区在新日期下重新查询并高亮该日期项

## 4. 筛选面板
- 4.1 发车时间
  - 控件：`#cc_start_time`下拉，含`00:00--24:00`分段（`车次列表-1.html:670-676`）
  - 场景：
    - Given 默认`00:00--24:00`
    - When 选择`06:00--12:00`
    - Then 列表仅显示该时间段内的车次
- 4.2 车次类型
  - 控件：GC/D/Z/T/K/QT/复/智复选（`车次列表-1.html:678-681`）
  - 场景：
    - Given 勾选`GC-高铁/城际`与`D-动车`
    - When 点击`筛选`提交
    - Then 列表仅显示所选类型车次
- 4.3 出发车站/到达车站筛选
  - 控件：两个`全部`入口与对应动态列表（`车次列表-1.html:683-691`）
  - 场景：
    - Given 展开`出发车站`
    - When 勾选`上海虹桥`
    - Then 列表限定为从该站出发的车次
- 4.4 车次席别筛选
  - 控件：`车次席别`复选（`车次列表-1.html:693-697`）
  - 场景：
    - Given 勾选`二等座`
    - When 应用筛选
    - Then 列表仅展示含该席别且有余票的车次或标注候补/无票
- 4.5 快捷购票配置（隐藏区域）
  - 乘车人选择（`请选择`弹窗，`车次列表-1.html:698-703`、弹窗`sel-buyer`见`车次列表-1.html:911-923`）
  - 优先车次（`add-train`，`车次列表-1.html:704-709`）与优先席别（`请选择优先席别`，`车次列表-1.html:710-714`，弹窗`sel-seat`见`车次列表-1.html:926-942`）
  - 备选日期（`请选择`，`车次列表-1.html:715-719`，弹窗`sel-date`见`车次列表-1.html:947-969`）
  - 高级设置：`席别优先/车次优先`、`自动提交`、`余票不足时部分提交`、`试听提示音乐`、`清空所有选项`（`车次列表-1.html:720-737`）
  - 场景（自动提交）：
    - Given 勾选`自动提交`
    - When 点击`查询`
    - Then 系统持续查询符合条件的车票并在满足条件时自动提交订单（提示文案见`车次列表-1.html:976-978`）
- 4.6 展开/收起筛选
  - 控件：`筛选`开关（`#show_more`）（`车次列表-1.html:744-747`）
  - 场景：
    - Given 面板处于收起状态
    - When 点击`筛选`
    - Then 高度展开至设定值，展示全部筛选项

## 5. 查询结果区
- 5.1 显示选项与统计
  - 控件：`显示折扣车次`、`显示积分兑换车次`、`显示全部可预订车次`（`车次列表-1.html:749-754`）
  - 场景：
    - Given 勾选`显示折扣车次`
    - When 刷新列表
    - Then 优先展示含折扣标识的车次与票价
- 5.2 表头与排序
  - 字段：`出发时间`、`到达时间`、`历时`可排序（`车次列表-1.html:764-766`）
  - 场景（按出发时间升序）：
    - Given 已有查询结果
    - When 点击`出发时间`
    - Then 列表按出发时间排序，指示样式变化
- 5.3 列字段
  - 车次、出发站/到达站、出发/到达时间、历时、`商务/特等`、`优选/一等`、`一等`、`二等/二等包座`、`高级软卧`、`软卧/动卧/一等卧`、`硬卧/二等卧`、`软座`、`硬座`、`无座`、`其他`、`备注`（`车次列表-1.html:761-785`）
  - 展示规则：余票列显示`有`/`候补`/`无`或具体数值；禁售/停售显示备注；价格显示折扣后票价说明（`车次列表-1.html:792-793`）
- 5.4 行内操作
  - 操作：`预订`、`候补`、`仅显示选定车次`（`车次列表-1.html:990-993`）
  - 场景（预订）：
    - Given 行内席别状态为`有`
    - When 点击该行`预订`
    - Then 进入下单流程并带入乘车人/席别偏好（如有）
- 5.5 无结果与提示
  - 类型：`没有符合筛选条件`、`5秒后继续查询`、`5秒后查询备选日期`、`未找到从X到Y列车`、`操作频率过快`（`车次列表-1.html:803-834`）
  - 场景（继续查询）：
    - Given 当前无符合条件车次
    - When 开启自动查询
    - Then 5秒后自动重试或切换备选日期
- 5.6 中转换乘提示
  - 提示位置与链接（`车次列表-1.html:789-801`）
  - 场景：
    - Given 用户在当前条件下无满足车次
    - When 查看提示
    - Then 可跳转到`中转换乘`页面查询换乘方案

## 6. 站点选择弹窗
- 结构：`国内站点/国际站点`切换、热门与字母分组、滚动列表、键盘导航（`车次列表-1.html:901-907`）
- 场景：
  - Given 打开站点选择弹窗
  - When 点击`热门`中的`上海`
  - Then 当前输入框填充`上海`并关闭弹窗

## 7. 乘车人/席别/日期选择弹窗
- 乘车人：搜索、刷新、分页（`车次列表-1.html:911-923`）
- 席别：最多选择5个席别（`车次列表-1.html:928-942`）
- 备选日期：最多选择5个日期（`车次列表-1.html:949-966`）
- 场景（席别优先）：
  - Given 在`选择席别`弹窗勾选`二等座`
  - When 返回主面板并点击查询
  - Then 查询逻辑按席别优先策略匹配车次

## 8. 无障碍与可用性
- 要求：输入框与按钮提供`aria-label`、`role`与键盘可操作提示（示例：`单程/往返`、站点输入、日期控件）（`车次列表-1.html:570-599`）
- 场景：
  - Given 用户使用键盘导航
  - When 聚焦搜索与日期元素
  - Then 可通过箭头/回车进行选择并听到提示音（试听按钮`tryPlayer`，`车次列表-1.html:735`）

## 9. 风控与频率限制
- 行为：操作频率过快提示与阻断（`车次列表-1.html:832-834`）
- 场景：
  - Given 用户连续快速点击查询
  - When 触发风控
  - Then 页面提示并禁止继续查询一段时间

## 10. 交互与性能
- 自动查询：在无票时周期性重试；在备选日期策略下切换查询（`车次列表-1.html:814-820`、说明见`车次列表-1.html:970-986`）
- 清空：一键清空筛选与偏好（`车次列表-1.html:736-737`）

## 11. UI风格与一致性（参考）
- 链接悬停色：`#fb7403`（`frontend/data/车次列表页/车次列表-1_files/common_css.css:7`）
- 主按钮：查询按钮`btn92s`为橙色底白字（以效果图与现网视觉为准）；按钮风格与首页`btn-primary`橙色（`#ff8000`）保持一致性（参考首页样式：`frontend/data/首页/首页_files/index_y_v50003.css:1`中`btn.btn-primary`定义）。

## 12. 接受标准
- 表单与日期快捷条联动，切换日期后结果刷新并高亮当前日期。
- 发车时间与车次类型筛选对结果集生效，可与站点/席别组合。
- 排序在`出发时间/到达时间/历时`三列工作正常且可切换方向。
- 余票状态显示清晰：`有/候补/无`或数值；`预订/候补`按钮根据状态可点击。
- 自动提交在符合条件时停止查询并进入下单；风控提示在频繁操作时出现。
- 弹窗选择（站点/乘车人/席别/日期）均可通过鼠标与键盘选择，最多5项限制生效。
- 无障碍提示覆盖主要交互控件，ARIA标签与键盘导航有效。

## 13. 功能性需求细化场景
- 输入合法性
  - Given 出发地与目的地为空
  - When 点击`查询`
  - Then 阻止提交并提示填写站点（入口在`车次列表-1.html:578-589`）
- 相同站点校验
  - Given 出发地与目的地相同
  - When 点击`查询`
  - Then 给出冲突提示并允许通过`互换`按钮修正（`车次列表-1.html:584`）
- 日期范围约束
  - Given 选择超出售票日历的日期
  - When 点击`查询`
  - Then 提示不可查询并引导选择日期快捷条中的有效日期（`车次列表-1.html:621-666`）
- 身份类型影响价格/余票
  - Given 选择`学生`
  - When 查询结果返回
  - Then 对应席别显示学生规则下的余票与价格标签
- 显示折扣/积分切换
  - Given 勾选`显示折扣车次`或`显示积分兑换车次`
  - When 重新查询或刷新列表
  - Then 结果中优先标注并排序显示相关车次（`车次列表-1.html:749-754`）
- 仅显示可预订车次
  - Given 勾选`显示全部可预订车次`
  - When 刷新列表
  - Then 隐藏不可预订或仅候补的车次（`车次列表-1.html:749-754`）
- 筛选与排序叠加
  - Given 已勾选车次类型与席别筛选
  - When 点击`出发时间`排序
  - Then 保留筛选条件并按选定列排序（`车次列表-1.html:764-766`）
- 快捷购票策略
  - Given 设定优先席别与备选日期，勾选`自动提交`
  - When 点击`查询`
  - Then 系统持续查询并在任一备选日期出现目标席别时自动提交（提示见`车次列表-1.html:970-978`）
- 清空配置
  - Given 已设置多项偏好
  - When 点击`清空所有选项`
  - Then 恢复筛选与偏好到初始状态（`车次列表-1.html:736-737`）

## 14. 非功能性需求场景
- 性能（端到端）
  - Given 正常网络环境
  - When 首次加载页面
  - Then 首屏可交互时间≤2.0s，筛选后列表刷新P95≤1.5s
- 可用性与无障碍
  - Given 使用键盘导航与读屏工具
  - When 操作查询表单与结果表格
  - Then 焦点可见、快捷键提示清晰、ARIA标签覆盖核心控件（`车次列表-1.html:570-599`、`735`）
- 一致性与视觉
  - Given 不同页面的主按钮
  - When 展示查询按钮
  - Then 颜色与交互风格与首页`btn-primary`橙色一致（参考`frontend/data/首页/首页_files/index_y_v50003.css:1`、车次列表链接悬停色`#fb7403`于`common_css.css:7`）
- 兼容性
  - Given 常见浏览器与窗口尺寸
  - When 使用筛选与弹窗
  - Then 不遮挡、不溢出，滚动列表在低分辨率下可操作（站点弹窗`车次列表-1.html:901-907`）
- 可靠性
  - Given 查询接口短暂失败
  - When 重试策略触发
  - Then 前端进行指数退避重试最多3次，并展示占位与提示
- 观测性
  - Given 用户点击查询/筛选/预订
  - When 上报埋点
  - Then 记录事件、耗时与错误码，便于容量与性能分析

## 15. 异常与边界场景
- 无结果
  - Given 条件过于严格
  - When 查询返回空
  - Then 显示无结果提示并建议放宽筛选或使用中转（`车次列表-1.html:803-809`、`789-801`）
- 操作频率过快
  - Given 连续快速点击查询或筛选
  - When 触发风控
  - Then 显示频率过快提示并短暂禁止操作（`车次列表-1.html:832-834`）
- 网络错误/超时
  - Given 接口超时或网络断开
  - When 查询失败
  - Then 显示重试入口与降级文案，保留已选条件
- 数据变更与售票策略更新
  - Given 某车次临时调整或停售
  - When 列表已展示旧数据
  - Then 标注`禁售/停售`于备注列并更新行内操作禁用（`车次列表-1.html:784-785`）
- 登录过期
  - Given 会话超时
  - When 点击`预订`
  - Then 弹出登录引导，登录后回到当前列表并保留条件
- 参数非法
  - Given 站点代码不在白名单或日期格式非法
  - When 提交查询
  - Then 前端阻止，后端返回400时展示友好错误
- 候补与余票切换
  - Given 某席别在刷新过程中由`有`变为`候补`
  - When 用户点击行内`预订`
  - Then 弹窗解释候补流程并引导到候补入口

## 16. 数据一致性与正确性场景
- 时区与日期
  - Given 跨天车次
  - When 展示出发/到达时间与历时
  - Then 确保日期跨天标识准确，历时计算正确（`车次列表-1.html:764-766`）
- 排序稳定性
  - Given 多行具有相同出发时间
  - When 按出发时间排序
  - Then 保持稳定排序，以车次号作为次序键
- 价格展示
  - Given 折扣活动更新
  - When 显示价格
  - Then 显示折扣后票价并提供公布票价链接（`车次列表-1.html:792-793`）

## 17. 安全与合规场景
- 输入防护
  - Given 用户输入站点与日期
  - When 发送查询参数
  - Then 转义与校验避免注入与非法字符
- CSRF/同源策略
  - Given 发起查询与跳转
  - When 跨页或同源请求
  - Then 遵循同源策略与CSRF令牌校验
- 隐私
  - Given 乘车人选择与偏好保存
  - When 本地缓存
  - Then 使用安全存储与过期策略，避免泄露

## 18. 监控与运维场景
- 指标
  - Given 每次查询
  - When 上报
  - Then 记录成功率、P50/P95耗时、无结果占比、风控命中率
- 日志
  - Given 异常
  - When 发生错误
  - Then 记录错误栈与接口返回码，便于排障
- 灰度/回滚
  - Given 新版筛选上线
  - When 命中问题
  - Then 支持快速开关与回滚到旧逻辑

## 19. 可用性与无障碍深化场景
- 键盘操作
  - Given 焦点在站点输入框
  - When 上下键浏览候选与回车选择
  - Then 正确填充并关闭弹窗（`车次列表-1.html:901-907`）
- 焦点管理
  - Given 打开任一弹窗
  - When 关闭弹窗
  - Then 焦点返回到触发按钮，避免键盘陷阱
- 对比度
  - Given 低对比度显示器
  - When 查看按钮与高亮
  - Then 对比度≥4.5:1，状态颜色可区分（参考`#fb7403`链接悬停色）

## 20. 验收指标补充
- 功能完整率≥95%基于场景用例通过率
- 查询成功率≥99.5%，风控命中后可恢复操作≤60s
- 无障碍操作覆盖率≥90%，读屏可读元素≥95%
- 观测数据覆盖率≥95%，关键事件漏报率≤1%
