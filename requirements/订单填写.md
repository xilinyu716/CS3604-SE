# 订单填写页需求场景树

## 功能性需求

### 1. 乘客管理

- 场景：新增乘客
  - Given 已登录并进入订单填写页
  - When 点击“新增乘客”入口
  - Then 弹出“新增乘客”对话框，支持填写姓名、证件类型与号码；可通过“关闭”按钮关闭（`frontend/data/订单填写/中国铁路12306网站.html:131`，`dialog_add_close`）

- 场景：修改乘客信息
  - Given 已选择某乘客
  - When 点击“修改乘客信息”入口
  - Then 弹出“修改乘客信息”对话框，支持更新证件类型与号码；可通过“关闭”按钮关闭（`frontend/data/订单填写/中国铁路12306网站.html:559`，`dialog_update_close`）

- 场景：删除乘车人
  - Given 乘客列表已加载
  - When 在目标乘客行点击删除图标
  - Then 删除该乘客，更新乘客列表与票价汇总（`frontend/data/订单填写/中国铁路12306网站.html:1474-1475`，`delPassengerInfo`）

- 场景：快速查询乘客
  - Given 乘客较多
  - When 在“输入乘客姓名”搜索框输入关键字
  - Then 列表按关键字过滤，仅显示匹配乘客（`frontend/data/订单填写/中国铁路12306网站.html:1360`，`quickQueryPassenger_id`）

- 场景：批量选择乘客
  - Given 乘客列表已加载
  - When 勾选“全选”复选框
  - Then 正常乘客与待核验乘客按规则批量勾选或取消（`frontend/data/订单填写/中国铁路12306网站.html:1365,1386`，`normal_passenger_id`,`dj_passenger_id`,`selected_ticket_passenger_all`）

- 场景：乘客信息区块呈现
  - Given 订单填写页打开
  - When 页面初始化
  - Then 显示“乘客信息”标题与说明，渲染乘客列表（`frontend/data/订单填写/中国铁路12306网站.html:1357-1359`）

- 场景：乘客输入校验提示
  - Given 乘客姓名或证件号码为空或格式错误
  - When 触发校验
  - Then 在对应行展示错误提示（`frontend/data/订单填写/中国铁路12306网站.html:1481-1483`，`txt-wrong`）
