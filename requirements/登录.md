- 合规与服务时段提示

  - When 用户进入登录页
  - Then 在页脚显示办理业务时段说明（`frontend/data/登陆/中国铁路12306网站.html:151-154`）
- 适老化模式
  - Given 用户开启“敬老版”或设置放大字体
  - When 页面切换适老样式
  - Then 字体与控件增大便于阅读（JS 切换：`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:214-218`）

## 2. 账号登录
- 表单字段：`J-userName` 用户名/邮箱/手机号，`J-password` 密码；错误提示区 `J-login-error`；提交按钮 `J-login`。
- 基础校验：用户名与密码必填；密码长度至少 6 位；用户名格式允许手机号/邮箱/会员名。
- 登录通道：统一认证登录（`web/login`）与本地登录（`loginAysnSuggest`）。

### 场景
- 登录成功（统一认证）
  - Given 输入合法用户名与密码
  - When 调用统一认证接口
  - Then 返回 `result_code==0` 隐藏遮罩并进入回调（`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:350-358`）
- 登录成功（本地登录）
  - Given 输入合法用户名与密码
  - When 提交到 `login/loginAysnSuggest`
  - Then `loginCheck=='Y'` 成功回调与隐藏错误（`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:463-470`）
- 用户名/密码缺失与长度校验
  - Given 用户名或密码为空，或密码长度<6
  - When 提交登录
  - Then 阻止提交并展示错误（错误展示：`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:224-243,254-258`；输入控件：`frontend/data/登陆/中国铁路12306网站.html:74-79`）
- 密码长期未修改提示
  - Given 后端返回 `result_code==101`
  - When 处理登录结果
  - Then 在错误区提示并提供重置链接（`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:369-373`）
- 错误消息展示与隐藏
  - Given 登录失败或校验失败
  - When 展示错误消息
  - Then 在 `J-login-error` 区显示并可聚焦，随后隐藏（`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:224-243,254-258`；HTML 错误区：`frontend/data/登陆/中国铁路12306网站.html:100-102`）

## 3. 滑块验证码与消息检查
- 场景触发：根据风控，先查询是否需要滑块或消息验证；支持“登录前校验”。
- 滑块库：`nc.js`，实例 `noCaptcha`。

### 场景
- 开启并完成滑块校验
  - Given 风控接口返回需要滑块
  - When 初始化 `noCaptcha` 并滑动完成
  - Then 组装 `sessionId/sig/if_check_slide_passcode_token` 并继续登录或消息检查（`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:1215-1223,1241-1293`）
- 登录前消息检查
  - Given 需要消息检查
  - When 调用 `base_checkUpMeg`
  - Then 允许则继续登录控制，不允许显示验证码错误（`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:259-289`）
- 风控结果引导（统一认证）
  - Given 统一认证返回风控码
  - When 处理 `result_code`
  - Then 91 显示上行短信验证码；92 显示下行短信流程；95 线下核验；94 APP 内核验；97 开启滑块（`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:110-153`；对应弹层：`frontend/data/登陆/中国铁路12306网站.html:156-189,190-277`）

## 9. 错误与异常处理
- 输入错误：就地提示并阻止提交（用户名/密码/验证码格式错误）。
- 二维码失效：显示遮罩与刷新入口。
- 网络异常：请求失败或超时隐藏遮罩并提示重试。
- 安全提示：密码过期/风控触发时弹层与引导。

### 场景
- 输入错误阻止提交
  - Given 表单项不合法
  - When 点击提交
  - Then 就地提示并阻止提交（`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:224-243,254-258`）
- 二维码失效与刷新
  - Given 扫码登录二维码过期
  - When 显示“二维码已失效”
  - Then 提供刷新按钮重新加载二维码（`frontend/data/登陆/中国铁路12306网站.html:121-125`）
- 网络异常提示
  - Given 登录或验证码请求失败
  - When 捕获错误
  - Then 隐藏遮罩并提示重试（`frontend/data/登陆/中国铁路12306网站_files/login_new_v20221230.js.下载:378-383,443-451`）

## 10. 非功能性需求
- 安全：滑块/图形验证码、消息检查、密码过期强提示与重置引导；统一认证跨域携带凭证。
- 可用性：错误反馈明确、遮罩与弹层交互一致、无障碍与适老化支持。
- 性能：接口超时 10s 设置；二维码与滑块初始化响应及时；避免重复请求。
- 一致性：按钮、图标与配色遵循全站规范（蓝 `#3b99fc`、橙 `#ff8000`、边框灰 `#dedede`）。

## 11. 验收清单（登录）
- 账号登录：必填与长度校验、统一认证/本地登录成功回调、错误展示与隐藏。
- 扫码登录：二维码加载/失效刷新/扫描成功提示与手机确认引导。
- 滑块与消息检查：触发、通过后继续登录或短信验证弹层交互正常。
- 找回密码：入口可用与重置流程可达。
- 可访问性与适老化：键盘、读屏与大字号样式有效（错误可聚焦）。
- 接口与退出：登录前置配置、登录、消息检查、二维码创建与校验接口连通。
