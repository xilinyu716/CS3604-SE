  - 场景：分页跳转

## 二、非功能性需求

- 性能
  - 场景：联系人列表加载
    - Given 常用联系人数据量在百级规模
    - When 用户首次进入或查询
    - Then 接口响应与列表渲染应在可接受时延内，分页与模板渲染不显著阻塞交互（接口/模板：`frontend/.../main_v30001.js.下载:39`、`frontend/.../中国铁路12306网站.html:1020-1221`）
- 安全
  - 场景：参数安全传递
    - Given 前端操作链接携带 `allEncStr` 等加密字段
    - When 进行删除/编辑等敏感操作
    - Then 服务端校验权限与签名，防止越权与参数篡改（`frontend/.../中国铁路12306网站.html:1066,1204-1209`）
- 可用性
  - 场景：可访问性与辅助文本
    - Given 无障碍工具启用
    - When 用户通过键盘导航
    - Then 所有主要操作具备明确的 `aria-label` 与焦点样式（`frontend/.../passengers.html.js.下载:526-547,553-561`）
- 一致性
  - 场景：按钮与图标风格一致
    - Given 页面使用统一的 `icon` 系列
    - When 渲染“添加/删除/编辑”等操作

## 三、异常处理

- 查询异常
  - 场景：网络错误
    - Given 查询接口请求失败
    - When 点击“查询”后返回异常
    - Then 显示错误提示，保持现有列表不变，并允许重试（接口：`topContactsUrl` 于 `frontend/.../main_v30001.js.下载:39`）
  - 场景：输入非法
    - Given 搜索框含非法字符或过长
    - When 执行查询
    - Then 进行前端校验或后端拒绝并提示，清理/截断非法输入（`frontend/.../passengers.html.js.下载:595-604` 提示框架）

- 删除异常
  - 场景：本人记录不可删除
    - Given 目标为“本人”记录
    - When 点击删除
    - Then 阻止删除并提示不可操作（`frontend/.../中国铁路12306网站.html:1193-1210`）
  - 场景：限制期未到
    - Given `delete_time` 限制期内
    - When 点击删除
    - Then 按钮置灰并提示具体日期（`frontend/.../中国铁路12306网站.html:1198-1203`）

- 编辑异常
  - 场景：数据校验失败
    - Given 编辑表单存在格式错误（如证件号）
    - When 提交编辑
    - Then 阻止提交并提示错误，保留输入供修正（接口：`editContactUrl` 于 `frontend/.../main_v30001.js.下载:39`）

- 核验状态异常
  - 场景：身份核验未通过/待核验
    - Given `total_times` 映射为未通过或待核验
    - When 渲染状态
    - Then 显示红色/灰色状态并提供须知提示（`frontend/.../中国铁路12306网站.html:1142-1165`）
  - 场景：手机号未核验
    - Given `if_receive!='Y'`
    - When 渲染状态
    - Then 显示“手机核验未通过/未核验”并提示后续处理（`frontend/.../中国铁路12306网站.html:1182-1186`）
