# 个人中心—个人信息 需求场景树

## 功能性需求

### 1. 基本信息查看与编辑

- 场景：展示基本信息区块
  - Given 已登录进入“查看个人信息”页面
  - When 页面初始化
  - Then 在右侧展示“基本信息”标题与表单区（`frontend/data/个人中心/个人信息/查看个人信息.html:675`，`1243`）

- 场景：查看用户名/国家与地区/证件类型/证件号码/核验状态
  - Given 基本信息已加载
  - When 查看表单标签
  - Then 显示字段标签与内容，包括“用户名/国家或地区/证件类型/证件号码/核验状态”（`frontend/data/个人中心/个人信息/查看个人信息.html:683,692,696,700,704`，`1262,1282,1286,1290,1294`）

- 场景：进入编辑模式
  - Given 处于查看模式
  - When 点击“编辑”按钮
  - Then 切换为可编辑态，字段可修改（`frontend/data/个人中心/个人信息/查看个人信息.html:1250,1254`，`basic_info_edit`）

- 场景：保存基本信息
  - Given 编辑完成
  - When 点击“保存”按钮
  - Then 校验通过后提交保存并返回查看态（`frontend/data/个人中心/个人信息/查看个人信息.html:1248,1251,1255`，`basic_info_save`）

- 场景：修改需输入密码提示
  - Given 用户未输入密码或密码未通过校验
  - When 尝试修改个人资料
  - Then 显示“正确输入密码才能修改个人资料”提示（`frontend/data/个人中心/个人信息/查看个人信息.html:790,1601`）

### 2. 身份核验与证件规则

- 场景：核验状态为已通过/预通过
  - Given 核验状态为“已通过/预通过”
  - When 展示核验入口
  - Then 显示“上传照片核验”入口与说明文案（`frontend/data/个人中心/个人信息/查看个人信息.html:1298-1305`，`upload`）

- 场景：核验状态为请报验/待核验
  - Given 核验状态为“请报验/待核验”
  - When 展示核验说明
  - Then 显示审核预计时长与线下核验指引（`frontend/data/个人中心/个人信息/查看个人信息.html:1308,1588,1592`）

- 场景：证件号码填写提示
  - Given 用户输入证件号码
  - When 聚焦或输入
  - Then 显示“用于身份核验，请正确填写”提示或“新版证件去除换证次数”提示（`frontend/data/个人中心/个人信息/查看个人信息.html:1424-1425,1455-1456`）

- 场景：姓名填写规则提示
  - Given 用户输入姓名
  - When 悬停“姓名填写规则”或聚焦输入框
  - Then 展示规则面板与示例（包含空格、符号、拼音替代等）（`frontend/data/个人中心/个人信息/查看个人信息.html:1359-1393`，示例图：`1038-1125`）

- 场景：证件有效期与出生日期填写
  - Given 证件类型需要有效期与出生日期
  - When 打开日期选择器并选择日期
  - Then 正确渲染日期控件并保存（`frontend/data/个人中心/个人信息/查看个人信息.html:1468,1481,1796`）

### 3. 联系方式管理

- 场景：展示联系方式区块
  - Given 页面加载完成
  - When 渲染联系方式卡片
  - Then 显示“联系方式”标题与编辑/保存按钮（`frontend/data/个人中心/个人信息/查看个人信息.html:1609,1611-1612`）

- 场景：查看手机号核验状态
  - Given 已绑定手机号
  - When 展示核验结果
  - Then 显示“已通过核验”或引导至“未通过核验”（`frontend/data/个人中心/个人信息/查看个人信息.html:1618,1626-1629`，跳转：`userSecurity_bindTel.html`）

- 场景：邮箱验证
  - Given 邮箱未验证
  - When 点击“验证邮箱”或“去安全邮箱修改”
  - Then 发送验证邮件或跳转至安全邮箱页面（`frontend/data/个人中心/个人信息/查看个人信息.html:1651,1696`）

- 场景：地址管理入口
  - Given 用户需维护联系地址
  - When 查看联系方式区块
  - Then 显示“地址”字段并提供管理入口（`frontend/data/个人中心/个人信息/查看个人信息.html:1655,1701`）

### 4. 附加信息

- 场景：附加信息编辑与保存
  - Given 附加信息区块可编辑
  - When 点击“编辑/保存”
  - Then 按校验规则更新附加信息（`frontend/data/个人中心/个人信息/查看个人信息.html:1716-1717,890-891`）

### 5. 左侧导航与入口

- 场景：个人信息导航展开
  - Given 左侧导航加载完成
  - When 展开“个人信息”菜单
  - Then 显示“查看个人信息/账号安全/手机核验/联系方式预留/地址管理”等入口（`frontend/data/个人中心/个人信息/查看个人信息.html:608,611,614,617,620,634`）

## 非功能性需求

### 6. 可访问性

- 场景：键盘跳转与辅助工具条
  - Given 页面加载辅助工具脚本
  - When 使用快捷键或跳转链接
  - Then 支持“跳转到导航区域/跳过导航”与工具条操作（`frontend/data/个人中心/个人信息/查看个人信息.html:69,1214`，工具条DOM：`1796`）

- 场景：可读性与提示文本
  - Given 链接与提示元素
  - When 悬停或聚焦
  - Then 显示明晰的提示文本与可读样式（例如 `a:hover` 配色：`frontend/data/个人中心/个人信息/查看个人信息_files/information_v70001.css:1`）

### 7. 安全

- 场景：编辑前密码校验
  - Given 用户未通过密码校验
  - When 进入编辑或保存
  - Then 拦截并提示输入密码（`frontend/data/个人中心/个人信息/查看个人信息.html:790,1601`）

- 场景：隐私信息最小化展示
  - Given 展示证件号码
  - When 渲染页面
  - Then 对证件号码进行适度脱敏与仅在可信上下文显示（参考证件字段：`frontend/data/个人中心/个人信息/查看个人信息.html:700,1290`）

### 8. 易用性与一致性

- 场景：按钮样式与位置一致
  - Given 页面包含“编辑/保存”按钮
  - When 渲染交互控件
  - Then 采用统一样式类`btn/btn-primary/btn-edit`并遵循右对齐布局（引用：`frontend/data/个人中心/个人信息/查看个人信息.html:800-801,1248-1255,1611-1612,1716-1717`）

- 场景：颜色与文字风格
  - Given 链接与提示文本
  - When 展示状态
  - Then 链接默认色接近`#333`，悬停为`#3b99fc`；强调提示色示例：`#ff8000`（`frontend/data/个人中心/个人信息/查看个人信息_files/information_v70001.css:1`，`frontend/data/个人中心/个人信息/查看个人信息.html:1304,1584`）

## 异常处理

### 9. 姓名规则不符合

- 场景：姓名包含不允许字符或格式
  - Given 输入姓名含空格、过多称谓或特殊符号
  - When 校验触发
  - Then 阻止保存并展示规则面板与示例图（`frontend/data/个人中心/个人信息/查看个人信息.html:1359-1393,1038-1125`）

### 10. 证件号码规则不符合

- 场景：证件号码不满足格式
  - Given 输入证件号码有非法字符或位数不正确
  - When 校验触发
  - Then 阻止保存并在证件号码处提示（`frontend/data/个人中心/个人信息/查看个人信息.html:1424-1425,1455-1456,1304`）

### 11. 证件有效期过期

- 场景：证件有效期已过或未填写
  - Given 证件类型为需有效期的类型
  - When 保存
  - Then 阻止并提示完善有效期（`frontend/data/个人中心/个人信息/查看个人信息.html:1468,1472`）

### 12. 核验状态阻断提交

- 场景：待核验或请报验状态下保存关键信息
  - Given 当前核验未通过
  - When 尝试保存与提交
  - Then 阻断并提示走“上传照片核验”或线下核验流程（`frontend/data/个人中心/个人信息/查看个人信息.html:1298-1305,1588-1592`）

### 13. 手机号未通过核验

- 场景：手机号状态为未核验
  - Given 手机未核验
  - When 点击“未通过核验”或“手机核验”入口
  - Then 跳转核验页面并引导完成验证（`frontend/data/个人中心/个人信息/查看个人信息.html:1629,854-856`）

### 14. 邮箱未验证

- 场景：邮箱未验证或验证失败
  - Given 邮箱处于未验证状态
  - When 点击“验证邮箱”或“安全邮箱修改”
  - Then 发送验证邮件或跳转到安全邮箱管理，失败时友好提示（`frontend/data/个人中心/个人信息/查看个人信息.html:1651,1696`）

### 15. 网络或保存失败

- 场景：编辑/保存过程中网络异常
  - Given 提交请求失败
  - When 保存基本信息/联系方式/附加信息
  - Then 保持编辑态，弹出错误提示并允许重试（引用按钮：`frontend/data/个人中心/个人信息/查看个人信息.html:1248-1255,1611-1612,1716-1717`）
