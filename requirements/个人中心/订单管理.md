## 三、异常处理

- 排队与出票
  - 场景：取消排队
    - Given 排队中
    - When 点击“取消排队”
    - Then 终止排队并更新订单状态（`frontend/.../中国铁路12306网站.html:671-691`）
  - 场景：排队失败
    - Given 失败页
    - When 选择“重新购票”
    - Then 返回购票流程（`frontend/.../中国铁路12306网站.html:693-705`）
  - 场景：出票失败
    - Given 出票失败
    - When 查看车次信息并点击“重新购票”
    - Then 回到预订页（`frontend/.../中国铁路12306网站.html:706-732`）

- 支付
  - 场景：倒计时到期
    - Given “网上支付(29分59秒)”倒计时完成
    - When 用户未支付
    - Then 订单失效并提示重新购票或撤销（操作区：`frontend/.../中国铁路12306网站.html:1873-1885`）
  - 场景：网络异常
    - Given 发起支付或取消
    - When 网络异常
    - Then 显示错误并保留当前状态，允许重试（确认弹窗定位：`frontend/.../toolbar.js.下载:3793-3802`）

- 改签/变更到站/灵活行
  - 场景：条件不满足
    - Given `resign_flag`/`syx_flag` 或发票状态限制
    - When 点击改签/灵活行/变更到站
    - Then 按禁用态显示并不可操作（`frontend/.../中国铁路12306网站.html:1460-1466,1483-1489,1491-1495`）

- 历史与退票
  - 场景：退款提示
    - Given 状态为“已退票，未退款”
    - When 渲染提示
    - Then 显示 180 日内凭证办理退款提示（`frontend/.../中国铁路12306网站.html:1436-1442,1732-1744`）
  - 场景：业务流水号弹层对焦
    - Given 键盘焦点在“业务流水号”
    - When Tab 导航
    - Then 弹层各字段可聚焦并可跳转到下一条（`frontend/.../train_order.html.js.下载:43-71,55-67`）

- 空态
  - 场景：无订单
    - Given 对应页签无数据
    - When 渲染空态
    - Then 显示引导文字与预订入口（`frontend/.../中国铁路12306网站.html:756-777,1007-1016`）
